# ⏳ EscapeWorld

EscapeWorld is a UI mobile app concept designed for time travel that allows users to curate journeys into both the past and the future. It features a dark-mode cyan-shade aesthetic, dynamic typography and personalised onboarding flows. The app guides travelers through selecting destinations, dates and trip durations to generate custom time-travel tickets.
